# Student Task Tracker

## About the Project
Student Task Tracker is a simple web application designed to help students organize and manage their daily tasks. It provides an easy-to-use interface for adding, completing, and deleting tasks.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and responsive interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the website.
2. Enter a task in the input box.
3. Click Add Task.
4. Mark tasks as completed or delete them when no longer needed.

## Purpose
This project was created to practice basic web development and learn Git and GitHub.
